Trainer Kit & Sarana Praktikum Siswa

Modul kurikulum vokasi SMKS Perikanan dan Kelautan Puger: memahami kalibrasi sensor perikanan, logika otomasi relay hysteresis, dan transmisi telemetri MQTT.

Modul 1: Kalibrasi Sensor

Kalibrasi probe pH (buffer 4.01 & 6.86) serta kompensasi suhu pada sensor TDS dan DO air payau.

Modul 2: Logika Otomasi ESP32

Memprogram relai aerator berdasarkan ambang batas dan proteksi hysteresis agar relay tidak cepat aus.

Modul 3: MQTT & Dashboard

Mengirimkan payload format JSON melalui MQTT Broker dan visualisasi grafik interpretasi hasil panen.

trainer_kit_smart_pond.ino (Cuplikan Praktik Siswa) C++ / Arduino IDE 
#define RELAY_AERATOR_PIN 23
#define DO_THRESHOLD_MIN  5.0 // mg/L

void evaluasiOksigen(float kadarDO) {
    if (kadarDO < DO_THRESHOLD_MIN) {
        // Oksigen kritis: Hidupkan aerator segera
        digitalWrite(RELAY_AERATOR_PIN, HIGH);
        kirimPeringatanTelegram("DARURAT: DO Turun ke " + String(kadarDO));
    } else if (kadarDO >= 5.4) {
        // Kondisi stabil dan hemat listrik: Matikan aerator
        digitalWrite(RELAY_AERATOR_PIN, LOW);
    }
}
